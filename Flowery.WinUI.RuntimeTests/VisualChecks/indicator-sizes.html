Indicator Sizes

DaisyToggle, DaisyCheckBox and DaisyRadio at their default token sizes in every size tier. Each indicator is as tall as the line height of its label text in the Windows type ramp, and Medium matches the WinUI defaults. At 100 % browser zoom one pixel here is one effective pixel in the app, because the browser and WinUI use the same Windows display scaling. The values mirror Flowery.WinUI/Theming/DaisyTokenDefaults.cs; update both together.

To match the app exactly, enter the Windows display scale (Settings › System › Display › Scale) and text size (Settings › Accessibility › Text size). The page then cancels any extra browser scaling, such as a browser that applies the Windows text size to the whole page, and enlarges only the labels with the WinUI text scaling formula, as WinUI does.
